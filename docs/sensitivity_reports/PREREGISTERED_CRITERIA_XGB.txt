Reproduction criterion (original data, original implementation): rerun is "reproduced" if macro pooled AUC and AP equal the archived values to 6 decimals AND archived vs rerun out-of-fold predictions have max abs difference <= 1e-6; otherwise reported as "not exactly reproduced" with the size of the discrepancy, and investigated before Phase 3.
2. No formal equivalence margin is defined for this study. Therefore results will be reported as numerical stability (size of changes, rank/class stability) and not as statistical equivalence.
3. Reference noise band (descriptive, fixed now): changes in macro AUC/AP and per-event metrics caused by changing only XGBoost random_state (42 -> 43 and 44) on the ORIGINAL Distance_River. A regenerated-minus-original change is described as "within the seed-noise band" if its absolute value does not exceed the largest absolute seed-change observed for the same metric. This is a descriptive comparison, not an equivalence test.
4. Consensus = (RF + XGB)/2 of out-of-fold probabilities (the rule in scripts/comparison/B09B...); unchanged. RF = archived original RF predictions.
5. Susceptibility classes = five equal-count percentile classes of the consensus score within each evaluated event (valid held-event rows); top-20% set = classes 5. Spatial agreement = Pearson, Spearman and top-20% Jaccard between original and regenerated consensus.
6. Primary regenerated vector = dist_vector.npy (documented vector regeneration workflow). Secondary = dist_raster30.npy.
